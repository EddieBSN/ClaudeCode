# Projects

This repository hosts multiple independent projects, each in its own folder.

| Project | Description |
|---------|-------------|
| [`task-crud/`](task-crud/) | Command-line task manager demonstrating SOLID architecture (Python, zero external dependencies) |
| [`brand-board/`](brand-board/) | Six-tile brand identity boards generated purely in code (HTML/SVG/CSS, headless export via Playwright) |
| [`landing-page/`](landing-page/) | Complete SaaS landing page for an invented product, coded to a studied design sensibility (self-contained HTML/SVG/CSS) |
| [`brand-reveal/`](brand-reveal/) | Five brand reveal frames (four invented brands plus the real flowtick identity): white lockups on generative canvas backgrounds, exported at 3840x2160 (HTML/SVG/canvas) |
| [`waitlist-hero/`](waitlist-hero/) | Editorial split waitlist hero for an invented brand (Understory): quiet cream UI beside a hand-coded SVG botanical illustration, exported at 3200x2000 (self-contained HTML/SVG) |

Each project folder contains its own README with usage and test instructions.
Run commands from inside the project folder.
