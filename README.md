# Projects

This repository hosts multiple independent projects, each in its own folder.

| Project | Description |
|---------|-------------|
| [`task-crud/`](task-crud/) | Command-line task manager demonstrating SOLID architecture (Python, zero external dependencies) |
| [`brand-board/`](brand-board/) | Six-tile brand identity boards generated purely in code (HTML/SVG/CSS, headless export via Playwright) |

Each project folder contains its own README with usage and test instructions.
Run commands from inside the project folder.
